## 🔄 Complete System Loop

```
                User Registration
                       ↓
                  User Login (user_id assigned)
                       ↓
            Browse Products (product.php)
                       ↓
            Click "Order Now" on Product
                       ↓
            managecart.php - Create DB Order
                       ↓
            Order Status: PENDING ⏳
                       ↓
         ┌─────────────────────────────────┐
         │   DATABASE has order record     │
         │   - user_id (WHO ordered)       │
         │   - item (WHAT they ordered)    │
         │   - price & qty                 │
         │   - timestamp (WHEN)            │
         │   - status (WHERE in process)   │
         └─────────────────────────────────┘
                       ↓
            Admin Dashboard sees it
                       ↓
              Admin confirms order
                       ↓
            Status: CONFIRMED ✓
                       ↓
            Admin marks as shipped
                       ↓
            Status: SHIPPED 📦
                       ↓
         Delivery arrives at customer
                       ↓
            Admin marks delivered
                       ↓
          Status: DELIVERED ✓✓ ✅ COMPLETE
                       ↓
          Order stored in history
          (Can view anytime)
```
